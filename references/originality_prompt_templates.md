# Prompt Templates

## Paragraph Revision

```text
请对下面中文学术段落做合规原创性提升：
1. 不编造数据、文献或结论；
2. 保留我的核心观点；
3. 标出需要补充引用的位置；
4. 减少重复句、模板化表达和空泛判断；
5. 输出：问题、修改稿、需补充来源、修改说明。

段落：
...
```

## Source-Grounded Synthesis

```text
请基于我提供的来源，重写下面段落，使其从“单篇文献复述”变成“多文献综合”：
1. 区分不同学者观点；
2. 写出共识、差异和不足；
3. 每个事实性主张都保留引用；
4. 不添加来源中没有的信息。
```

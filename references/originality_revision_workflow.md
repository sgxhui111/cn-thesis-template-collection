# Revision Workflow

## Level 1: Diagnose

Run the workflow script to identify:

- repeated sentences
- repeated 4-6 character phrases
- long sentences
- citation gaps
- filler phrases
- paragraphs with weak claim-evidence structure

## Level 2: Ask For Evidence

For each high-risk paragraph, check whether the paragraph has:

- a specific claim
- data or example
- source or citation
- the student's own interpretation
- clear relationship to the thesis topic

If not, ask for missing material before rewriting.

## Level 3: Rewrite Safely

Use this order:

1. State the paragraph claim.
2. Add or preserve evidence.
3. Cite source-dependent claims.
4. Explain what the evidence means.
5. Connect to the next paragraph.

Avoid purely cosmetic synonym replacement. Cosmetic rewriting often leaves the repetition and integrity risk intact.

## Level 4: Revision Log

For every revised paragraph, record:

- original issue
- revision action
- citation added or needed
- whether meaning changed
- remaining risk
